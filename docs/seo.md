# SEO-продвижение сайта «Подсолнух»

Гостиница: **Краснодар, Прикубанский округ, СТ4 Топольки, ул. Цветочная, 162**.
Основные аудитории (исходя из данных сайта и расположения): гости посуточно, родственники и абитуриенты
(Университет МВД, лётное училище, призывной пункт рядом), участники выставок «Экспоград-Юг», командированные
(ТЦ «Красная площадь», Дзержинского), семьи до 4 гостей (своя кухня), путешественники на авто (парковка).

## Что нужно сделать вручную (вне кода)

Это даёт основной эффект для локального продвижения в Краснодаре и не делается правками файлов.

1. **Яндекс Вебмастер** — добавить сайт `https://podsolnuh.io`, подтвердить права (мета-тег вставить в `<head>`
   обеих страниц), отправить `sitemap.xml`, указать регион «Краснодар».
2. **Google Search Console** — то же самое, отправить `sitemap.xml`.
3. **Яндекс Бизнес (Яндекс Карты)** — создать/заполнить карточку организации: адрес «Краснодар, ул. Цветочная, 162»,
   телефон, сайт, фото номеров, режим работы, рубрика «Гостиница». Попросить гостей оставлять отзывы.
4. **2ГИС и Google Business Profile** — аналогичные карточки с тем же названием, адресом и телефоном (NAP должны
   совпадать с сайтом: «Гостиница «Подсолнух», Краснодар, ул. Цветочная, 162, 8 918 116-45-54»).
5. **Яндекс Метрика** (и по желанию Google Analytics) — счётчик и цели: клик по телефону, клик MAX/Telegram,
   отправка заявки. Без этого результат продвижения не измерить.
6. **Площадки бронирования** — Яндекс Путешествия, Островок, Суточно.ру, Авито и др.: ссылка на сайт из карточки
   даёт обратные ссылки и трафик.
7. **Отзывы** — просить гостей оставлять отзывы на Яндекс Картах и 2ГИС: главный фактор в локальной выдаче.
8. **Фото** — загружать реальные фото номеров, двора и парковки в карточки на картах (в сайте у фото уже есть `alt`).

## Важно проверить

- **Домен.** В коде везде используется `https://podsolnuh.io/`. GitHub Pages сейчас отдаёт сайт на
  `https://ckot23.github.io/podsolnuh.io/` без привязанного домена. Если `podsolnuh.io` ещё не подключён,
  в настройках Pages нужно указать Custom domain и настроить DNS (тогда GitHub сам создаст файл `CNAME`).
  Если домен другой — замените `podsolnuh.io` во всех файлах (`grep -rl podsolnuh.io .`).
- **Координаты.** В `geo` указаны приблизительные координаты Топольки-4 (45.0994, 38.9913),
  взятые по соседнему дому на ул. Цветочной. Откройте карточку на Яндекс Картах и при необходимости
  замените на точные значения в `index.html` и `rooms.html`.
- **Цены.** На сайте цена не указана («зависит от даты и числа гостей»). Если появятся ориентировочные цены —
  добавьте `priceRange` в разметку `Hotel` и текст «от … ₽/сутки» в `title`/`description`: это заметно повышает CTR.
- **Новые страницы.** Для роста по запросам стоит делать отдельные страницы под интент, например
  «Гостиница рядом с Экспоград-Юг», «Гостиница рядом с Университетом МВД», «Номера с кухней посуточно».
  Добавляйте их в `sitemap.xml`.
