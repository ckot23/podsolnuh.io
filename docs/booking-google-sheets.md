# Брони в Google Таблице + уведомления в Telegram

Как это работает:

```
Гость на сайте → нажимает «Забронировать» → заявка уходит в Google Таблицу
                                            → модератору в Telegram приходит сообщение
                                              с кнопками «✅ Подтвердить» / «❌ Отклонить»
```

Никакого сервера и ежемесячных платежей не нужно: всё делает бесплатный Google Apps Script
(скрипт внутри таблицы). Сайт остаётся статическим.

Файл со скриптом лежит в репозитории: **`google-sheets/Code.gs`** — его нужно скопировать в таблицу.

> **Текущее состояние:** URL веб-приложения записан в `data/site.json` → `cfg.bookingApi`. Если
> Telegram получает заявки, а строки в таблице нет, обновите код Apps Script по инструкции ниже
> и создайте новую версию развёртывания. Сайт больше не считает отправку только в Telegram успешной:
> заявка подтверждается лишь по ответу о записи строки или проверке `action=verify`.

---

## Что понадобится

| Что | Где взять |
|---|---|
| Google-аккаунт | у вас уже есть |
| Telegram-бот (для уведомлений) | @BotFather в Telegram |
| Ваш chat_id в Telegram | @userinfobot в Telegram |

Текущий chat_id получателя заявок — `7114829971`. Можно указать несколько через запятую
(например, свой и администратора на ресепшене).

---

## Шаг 1. Создайте Google Таблицу

1. Откройте <https://sheets.new> — создастся новая таблица.
2. Назовите её, например, «Подсолнух — брони».

Лист «Брони» и оформление скрипт создаст сам, вручную ничего рисовать не надо.

## Шаг 2. Вставьте скрипт

1. В таблице: **Расширения → Apps Script**.
2. Удалите заготовку `function myFunction() {}`.
3. Откройте в репозитории файл `google-sheets/Code.gs`, скопируйте **весь** текст и вставьте в редактор.
4. Нажмите 💾 (Сохранить).

## Шаг 3. Заполните настройки в начале файла

```js
var BOT_TOKEN = '123456789:AA...';   // токен бота от @BotFather
var MODERATOR_CHAT_ID = '7114829971'; // кому присылать заявки (можно несколько через запятую)
var SHEET_ID = '';                    // оставьте пустым, если скрипт открыт из самой таблицы
var SHEET_NAME = 'Брони';
var WEBHOOK_SECRET = 'podsolnuh-2026'; // придумайте свою строку — защита кнопок «Подтвердить»
var TIMEZONE = 'Europe/Moscow';
```

**Как получить токен бота:** напишите @BotFather команду `/newbot`, придумайте имя — в ответ придёт
токен вида `123456789:AAFG...`. Если бот уже есть — `/mybots` → выбрать бота → *API Token*.

> ⚠️ **Важно про безопасность.** В старом файле `data/site.json` токен бота лежал в открытом виде —
> его мог увидеть любой посетитель сайта (и он уже был опубликован в GitHub). Такой токен нужно
> **отозвать**: @BotFather → `/mybots` → ваш бот → *API Token* → *Revoke current token*. Новый токен
> вставляйте **только в Apps Script**, в файлы сайта его больше класть не нужно.

## Шаг 4. Запустите `setup()`

1. В редакторе Apps Script выберите функцию **`setup`** и нажмите **▶ Выполнить**.
2. Google попросит разрешения: *Просмотреть разрешения* → выбрать аккаунт → *Дополнительные настройки* →
   *Перейти к проекту (небезопасно)* → *Разрешить*. Это стандартный шаг для собственных скриптов.
3. Внизу в журнале появится: `Таблица готова…`, `Telegram: бот @... на связи`.
   Если написано «ошибка» — проверьте токен и chat_id.

## Шаг 5. Разверните веб-приложение (сайт будет сюда писать)

1. Если веб-приложение уже развёрнуто: **Развернуть → Управление развёртываниями** → ✏️ изменить →
   выберите **Новая версия** → **Развернуть**. Если это первое развёртывание: **Развернуть → Новое развёртывание**.
2. При первом развёртывании выберите тип **Веб-приложение**.
3. Заполните:
   - *Описание* — любое, например `брони`;
   - **Запуск от имени: `Я`**;
   - **У кого есть доступ: `Все`** ← обязательно, иначе сайт не сможет отправить заявку.
4. Нажмите **Развернуть** и скопируйте **URL веб-приложения** — он заканчивается на `/exec`:

   ```
   https://script.google.com/macros/s/AKfycb.../exec
   ```

## Шаг 6. Включите кнопки «Подтвердить / Отклонить»

1. В Apps Script выберите функцию **`setupTelegram`** и нажмите ▶ Выполнить.
2. В журнале будет `setWebhook: {"ok":true, …}` — значит кнопки подключены.

> Важно: если позже вы сделаете **новое развёртывание** (URL изменится), запустите `setupTelegram()`
> ещё раз — вебхук всегда должен указывать на актуальный `/exec`.

## Шаг 7. Вставьте ссылку на сайте

1. На сайте откройте подвал → **Админ-панель** → пароль (по умолчанию `sunflower`).
2. В поле **📊 Google-таблица броней** вставьте скопированный URL `/exec`.
3. Нажмите **🔍 Проверить связь с таблицей и Telegram** — должно ответить
   «✅ Таблица … на связи, заявок: 0, Telegram подключён».
4. Нажмите **Сохранить настройки**.

Пока URL не указан глобально (через `data/site.json`), его видит только ваш браузер.
Чтобы бронь работала у **всех посетителей**, добавьте тот же URL в `data/site.json`:

```json
"cfg": {
  "tgUrl": "https://t.me/ckot_23",
  "waNumber": "79882443223",
  "phonePrimary": "+79181164554",
  "bookingApi": "https://script.google.com/macros/s/AKfycb.../exec"
}
```

Либо заполните GitHub-синхронизацию в админ-панели (поле GitHub-токен) и нажмите
**🔄 Применить для всего сайта** — тогда файл обновится сам.

## Шаг 8. Проверка

1. Откройте `rooms.html`, выберите номер, даты и отправьте заявку.
2. В таблице появится строка со статусом **Новая**, а модератору придёт сообщение в Telegram.
3. Нажмите в сообщении **✅ Подтвердить** — статус в таблице станет **Подтверждена**,
   а номер на сайте автоматически подсветится как «🚫 Занят» (для броней, покрывающих сегодняшний день).

Быстрая самопроверка из браузера (без оформления настоящей брони гостя):

```bash
LIVE=1 node demo/serve.js      # http://localhost:4173/selftest
```

На странице `/selftest` две кнопки: «Проверить связь» (покажет имя таблицы, число заявок и статус
бота) и «Отправить тестовую заявку» (создаст строку «Проверка сайта (тест)» и сообщение в Telegram —
и то, и другое можно удалить).

## Что видно в таблице

| Колонка | Смысл |
|---|---|
| № | номер заявки (по нему же приходят подтверждения) |
| Дата заявки | когда гость отправил заявку |
| **Статус** | выпадающий список: Новая → Подтверждена / Отклонена → Заселена → Завершена |
| Имя, Телефон | контакты гостя (телефон в Telegram — одним касанием для звонка) |
| Заезд, Выезд, Ночей | даты; считаются автоматически |
| Гостей, Номер, Цена/сутки, Сумма | что бронирует; сумма = цена × ночей (предварительная) |
| Комментарий | пожелания гостя |
| Источник | страница сайта, с которой пришла заявка |
| Ref, RoomId | технические: защита от дублей и связь со статусами номеров |

Статусы можно менять вручную прямо в таблице — сайт учитывает значения
**Подтверждена** и **Заселена** при показе занятых номеров.

## Команды бота

Бот отвечает модератору (только на chat_id из `MODERATOR_CHAT_ID`):

- `/start` — короткая справка;
- `/status` — какие номера заняты сегодня;
- `/today` — заявки, пришедшие за сегодня.

## Что уже защищено

- **Ловушка для ботов** — скрытое поле в форме: спам-роботы отсекаются.
- **Защита от дублей** — повторная отправка того же гостя (ref или телефон + дата в течение 15 минут)
  не создаёт вторую строку; сайт при обрыве связи сам переспрашивает таблицу, принята ли заявка.
- **Только модератор** может нажимать кнопки: апдейты Telegram принимаются лишь с секретом
  `WEBHOOK_SECRET`, а нажатия — только с chat_id из `MODERATOR_CHAT_ID`.
- **URL веб-приложения публичен** (иначе браузер не смог бы отправить заявку), поэтому в заявке
  обязательны имя и телефон, а размер полей ограничен. Если начнётся спам — поменяйте
  `WEBHOOK_SECRET`/`SHEET_NAME` не поможет: просто создайте новое развёртывание и обновите URL на сайте.

## Если что-то не работает

| Симптом | Причина и решение |
|---|---|
| Заявка приходит только в Telegram, строки в таблице нет | На сайте или в Apps Script осталась старая Telegram-only версия. Обновите сайт до текущего `js/app.js`, замените код Apps Script содержимым `google-sheets/Code.gs`, сохраните и разверните **новую версию**. Проверьте, что `cfg.bookingApi` указывает на актуальный URL `/exec`; затем запустите `LIVE=1 node demo/serve.js`, откройте `/selftest` и убедитесь, что выросло число строк. |
| Сайт пишет «Не удалось отправить заявку» | Проверьте в админ-панели кнопку «🔍 Проверить связь». Проверьте URL `/exec` и доступ веб-приложения: **Все**. После изменения `Code.gs` нужно развернуть новую версию. |
| Заявка приходит в таблицу, но нет сообщения в Telegram | Неверный `BOT_TOKEN` или `MODERATOR_CHAT_ID`. Запустите `testConnection()` — он покажет ошибку. Ещё вариант: вы не написали боту ни одного сообщения — нажмите *Start* в чате с ботом. |
| Кнопки «Подтвердить/Отклонить» не работают | Не запущен `setupTelegram()` или после переразвёртывания изменился URL — запустите `setupTelegram()` снова. |
| Онлайн-заявка недоступна | В `data/site.json` не указан `bookingApi`, либо Apps Script не отвечает. Проверьте связь в админ-панели и укажите действующий URL `/exec`. Сайт не отправляет заявки напрямую в Telegram. |
| Номера не становятся «занятыми» | Статус брони должен быть **Подтверждена** или **Заселена** и бронь должна покрывать сегодняшний день; колонка `RoomId` не должна быть пустой. |

Лимиты Google бесплатного аккаунта (количество запросов к Apps Script и Telegram в сутки) для
гостиницы на 7 номеров избыточны — упереться в них практически невозможно.
