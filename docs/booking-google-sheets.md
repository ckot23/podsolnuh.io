# Заявка на бронь → Google Таблица → Telegram

На странице бронирования выбор номеров убран — гость указывает **только имя и номер телефона**.

Сайт отправляет заявку в веб-приложение Google Apps Script. Скрипт **сначала записывает строку в таблицу**,
затем через Telegram-бота отправляет модератору сообщение **«🌻 Новая заявка №…»** с именем и телефоном.
Кнопки «✅ Подтвердить» / «❌ Отклонить» меняют скрытый статус заявки в таблице.

> **Важно:** изменение `google-sheets/Code.gs` в GitHub не обновляет уже развёрнутый Apps Script.
> Чтобы применить новый формат к действующей Google Таблице, её владелец должен обновить код и
> развёртывание по шагам ниже. Ссылка `/exec` уже указана в `data/site.json` → `cfg.bookingApi`.

## Если таблица и бот уже подключены

1. Откройте действующую таблицу → **Расширения → Apps Script**.
2. Убедитесь, что в **Настройки проекта → Свойства скрипта** сохранены:
   - `BOT_TOKEN` — действующий токен бота;
   - `MODERATOR_CHAT_ID` — chat_id модератора (несколько получателей через запятую).
3. Замените **весь** `Code.gs` содержимым файла **`google-sheets/Code.gs`** из репозитория и сохраните.
4. **Развернуть → Управление развёртываниями → ✏️ Изменить → Новая версия → Развернуть**
   (запуск — **от вашего имени**, доступ — **Все**). URL `/exec` при обновлении существующего развёртывания
   остаётся прежним, `data/site.json` менять не нужно.
5. Выполните **`setup()`**. Скрипт создаст резервный лист **«Брони — архив …»** со всеми прежними колонками,
   перестроит рабочий лист и оставит только две видимые колонки: **Имя** и **Телефон** (номера заявок,
   даты создания, статусы и `Ref` сохраняются в скрытых колонках).
6. Проверьте связь: откройте в браузере URL `/exec` с параметром `?action=ping` — в ответе должны быть
   `ok: true`, имя листа, число заявок и состояние Telegram. Затем отправьте тестовую заявку с сайта.

## Как выглядит рабочая таблица

Видимы **только два поля из формы**:

| Имя | Телефон |
|---|---|
| Анна | +7 918 000-00-00 |

Номер телефона хранится текстом, чтобы не потерять `+` и ведущие нули.
Четыре служебные колонки **скрыты**: `№заявки`, `Дата заявки`, `Статус`, `Ref`.

## Сообщение модератору

```text
🌻 Новая заявка №1

🕒 Дата заявки: 20.10.2026 10:30
👤 Имя: Анна
📞 Телефон: +7 918 000-00-00

Статус в таблице: Новая
[✅ Подтвердить] [❌ Отклонить]
[📊 Открыть таблицу]
```

Команды бота: `/start` (справка), `/today` (заявки за сегодня).

## Локальная проверка без Google и Telegram

```bash
node google-sheets/tests/backend.test.js
node demo/serve.js
```

Демо: `http://localhost:4173/rooms.html`. Заявки записываются в локальную мок-таблицу;
на `http://localhost:4173/demo/sheet` видны записанные `Имя` и `Телефон` и предпросмотр сообщения модератору.
