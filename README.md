# podsolnuh.io

Сайт гостиницы «Подсолнух» в Краснодаре со страницей онлайн-заявки на бронь.
Проект не требует сборщика и готов к размещению на GitHub Pages или обычном static hosting.
Запускайте через HTTP: JavaScript использует ES-модули.

## Структура

- `index.html` — главная страница и SEO-метаданные.
- `rooms.html` — страница заявки на бронь (только имя и номер телефона).
- `near/*.html` — 6 отдельных страниц блока «Рядом с «Подсолнухом»»: у каждой
  своя фотогалерея с лайтбоксом, свой `<title>`, `description`, canonical,
  Open Graph и разметка Schema.org (BreadcrumbList + TouristAttraction/WebPage).
- `data/near-places.json` — тексты, факты и списки фотографий для этих страниц.
- `tools/build-near-pages.js` — генератор `near/*.html`, `sitemap.xml` и `robots.txt`.
- `img/near/*.jpg|webp` — фотографии для страниц «Рядом».
- `sitemap.xml`, `robots.txt` — карта сайта и правила для поисковых роботов.
- `css/site.css` — стили, адаптивная сетка и анимации.
- `js/app.js` — валидация формы, модалки и отправка заявки в Google Таблицу.
- `data/site.json` — общие контакты и URL Apps Script в `cfg.bookingApi`.
- `google-sheets/Code.gs` — чистый скрипт для новой Google Таблицы (только 2 колонки: `Имя` и `Номер телефона`).
- `docs/booking-google-sheets.md` — пошаговая инструкция по созданию новой таблицы и развёртыванию Apps Script.
- `demo/serve.js` — локальное демо с настоящим `Code.gs` на мок-таблице и мок Telegram.
- `google-sheets/tests/backend.test.js` — автопроверки приёма заявок и записи в таблицу.
- `img/*.webp` — оптимизированные фотографии; JPG оставлены как fallback.

## Бронирование: только имя и номер телефона

При оформлении заявки гость заполняет только два поля:

1. **Имя**
2. **Номер телефона**

В Google Таблице создаются ровно две колонки без лишних и скрытых столбцов:

```text
Имя | Номер телефона
```

Подробная инструкция по созданию новой таблицы и подключению скрипта: **[docs/booking-google-sheets.md](docs/booking-google-sheets.md)**.

## Не приходит заявка от бота?

Заявка всё равно записывается в таблицу — теряется только уведомление.
Выполните в редакторе Apps Script функцию **`diagnose`**: она по шагам проверит токен,
`chat_id`, реальную отправку и версию развёртывания и напечатает причину в журнале.
Разбор всех случаев — в **[docs/booking-google-sheets.md](docs/booking-google-sheets.md#не-приходит-заявка-от-бота)**.

## Страницы блока «Рядом»

Каждая карточка в блоке «Рядом с «Подсолнухом»» на главной ведёт на свою
страницу: фотографии, описание, факты, карта и кнопки брони.

| Карточка | Страница | Отдельный SEO-заголовок |
| --- | --- | --- |
| Краевой призывной пункт | `near/prizyvnoy-punkt.html` | «Краевой призывной пункт рядом с гостиницей «Подсолнух» — Краснодар» |
| Университет МВД | `near/universitet-mvd.html` | «Университет МВД рядом с гостиницей «Подсолнух» в Краснодаре» |
| Лётное училище | `near/letnoe-uchilishche.html` | «КВВАУЛ — лётное училище рядом с гостиницей «Подсолнух», Краснодар» |
| ТЦ «Красная площадь» | `near/trc-krasnaya-ploshchad.html` | «ТЦ «Красная площадь» рядом с гостиницей «Подсолнух» в Краснодаре» |
| «Баскет-холл» | `near/basket-holl.html` | «Гостиница рядом с Баскет-холлом в Краснодаре — «Подсолнух»» |
| «Экспоград-Юг» | `near/ekspograd-yug.html` | ««Экспоград-Юг» рядом с гостиницей «Подсолнух» — Краснодар» |

Страницы статические: тексты и мета-теги лежат в HTML, поэтому индексируются
без выполнения JavaScript. Чтобы изменить текст, факты, порядок или набор фото:

1. отредактируйте `data/near-places.json` (описание, `seoTitle`, `seoDescription`,
   `gallery`, `facts` и т.д.);
2. положите картинки в `img/near/` парами `<имя>.jpg` + `<имя>.webp`
   (шириной до 1600 px) и укажите `<имя>` в поле `gallery`;
3. пересоберите страницы и карту сайта:

```bash
node tools/build-near-pages.js
```

После сборки обновите `?v=` у `css/site.css` и `js/app.js` в HTML, если меняли стили
или скрипт, чтобы браузеры гостей не взяли старую версию из кэша.

### Фотографии страниц «Рядом»

Снимки взяты из открытых источников и приведены к единому размеру (JPG + WebP):

- призывной пункт — оставлены два исходных снимка: фасад с флагом и вход (Яндекс Карты; точный адрес съёмки не подтверждён).
- «Баскет-холл»: `basket-holl-1` — Елена Синеок, Юга.ру, https://www.yuga.ru/articles/sport/8755.html;
  `basket-holl-2` — https://biletovmir.ru/krasnodar/cportivnyy-kompleks-basket-holl.
  Водяной знак автора сохранён. Права на публикацию необходимо согласовать до размещения;
- университет МВД — kuban24.tv (выпуск и построение на плацу, 2025);
- лётное училище — rus.team (КВВАУЛ: учебная стоянка и самолёт у проходной);
- ТЦ «Красная площадь» — autocenter71.ru, Яндекс Карты (свежий интерьер);
- «Экспоград-Юг» — expograd-yug.ru (фасад с улицы, кафе, павильон).

Перед публикацией под своими ключами лучше заменить их на собственные снимки:
у чужих фотографий остаются вопросы по авторским правам. Достаточно положить
файлы с теми же именами в `img/near/` и запустить сборку.

## Локальный запуск и проверки

```bash
node google-sheets/tests/backend.test.js   # автотесты скрипта таблицы
node demo/serve.js                         # локальное демо (http://localhost:4173/rooms.html)
```
