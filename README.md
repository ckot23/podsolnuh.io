# podsolnuh.io

Сайт гостиницы «Подсолнух» в Краснодаре с отдельной страницей каталога номеров.
Проект не требует сборщика и готов к размещению на GitHub Pages или обычном static hosting.
Запускайте через HTTP: JavaScript использует ES-модули.

## Структура

- `index.html` — главная страница и SEO-метаданные.
- `rooms.html` — каталог семи номеров и простая форма бронирования.
- `css/site.css` — стили, адаптивная сетка и анимации.
- `js/app.js` — календарь, слайдеры, модалки, админ-панель и отправка заявки в Google Таблицу.
- `js/rooms.js` — данные номеров и фотографии.
- `data/site.json` — общие статусы, контакты и URL Apps Script в `cfg.bookingApi`.
- `google-sheets/Code.gs` — приём заявки, запись в таблицу, уведомление модератору и кнопки Telegram.
- `docs/booking-google-sheets.md` — подключение и обновление действующей таблицы/Apps Script.
- `demo/serve.js` — локальное демо с настоящим `Code.gs` на мок-таблице и мок Telegram.
- `google-sheets/tests/backend.test.js` — автопроверки формы данных, миграции, дублей и Telegram без аккаунта Google.
- `img/*.webp` — оптимизированные фотографии; JPG оставлены как fallback.

## Локальный запуск

Только статический сайт:

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

Демо с работающим локальным приёмом заявок:

```bash
node demo/serve.js
```

Откройте <http://localhost:4173/rooms.html>. На `/demo/sheet` видны записанные данные и
предпросмотр сообщения Telegram. Демо **не отправляет** данные в настоящий Google или Telegram.

## Бронирование: пять полей

Гость указывает только:

1. Имя.
2. Номер телефона.
3. Заезд и выезд в существующем календаре.
4. Номер комнаты (компактный выбор из семи номеров).
5. Нужны ли отчётные документы — необязательная галочка.

Количество гостей, комментарий и повторная сводка удалены. Вместо дополнительной галочки
согласия под кнопкой размещена ссылка на политику обработки данных.

Все пять полей уходят в **Google Таблицу**, затем модератору приходит сообщение
**«🌻 Новая заявка №…»** через **Telegram-бота**. Кнопки «✅ Подтвердить» / «❌ Отклонить»
сохраняются; подтверждённые брони на сегодня отмечают номер занятым на сайте.

В рабочей таблице видны только:

```text
Имя | Телефон | Заезд/выезд | Номер комнаты | Отчётные документы
```

Пять технических колонок для доставки, времени, номера и статуса заявки скрыты.
При смене старого формата скрипт сначала создаёт **резервную копию всего прежнего листа**, затем
переносит нужные поля и статусы. Старые количества гостей и комментарии сохраняются только в архиве.

### Применение к действующей таблице

**Обновление файлов сайта не обновляет развёрнутый Apps Script автоматически.**
Владелец таблицы должен:

1. Сохранить токен/получателей бота в свойствах Apps Script и заменить код файлом `google-sheets/Code.gs`.
2. Развернуть **новую версию** существующего веб-приложения, затем выполнить `setup()` для переноса данных.
3. Выполнить `setupTelegram()` и проверить тестовую заявку: запись в таблице **и** сообщение в Telegram.

Подробные шаги: **[docs/booking-google-sheets.md](docs/booking-google-sheets.md)**.
URL `/exec` уже записан в `data/site.json` → `cfg.bookingApi`; при обновлении того же развёртывания
его обычно не нужно менять.

> ⚠️ Старый Telegram-токен публиковался в файлах сайта и GitHub. Считайте его скомпрометированным:
> отзовите через @BotFather. Новый храните только в **свойствах Google Apps Script** (`BOT_TOKEN`),
> не в репозитории, браузере или чате. `MODERATOR_CHAT_ID` задаётся там же.

Заявка считается принятой только после подтверждённой записи строки. Если Google недоступен,
сайт показывает ошибку и сохраняет заполненную форму. Если запись прошла, но Telegram недоступен,
заявка остаётся в таблице, а гость видит предупреждение. Повтор одной заявки не создаёт вторую строку.

## Проверки

```bash
node google-sheets/tests/backend.test.js   # без зависимостей и внешних запросов
LIVE=1 node demo/serve.js                  # реальные интеграции; /selftest создаёт тестовую заявку
```

Самопроверка настоящего Apps Script — на `/selftest` в режиме `LIVE=1`.
Отправка теста там действительно создаёт строку в Google Таблице и уведомление в Telegram.

## Оптимизации

- CSS и JavaScript вынесены из HTML для отдельного кэширования.
- Фотографии — WebP с JPG-fallback, lazy loading, заданными размерами и preload для hero.
- Каталог отделён от логики приложения.
- Open Graph/Schema.org, noscript-подсказка, доступные модальные окна и навигация по выбору номера с клавиатуры.
