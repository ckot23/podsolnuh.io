# podsolnuh.io

Сайт гостиницы «Подсолнух» в Краснодаре с отдельной страницей каталога номеров.

## Структура

- `index.html` — главная страница и SEO-метаданные; каталог номеров вынесен отдельно.
- `rooms.html` — страница с фотографиями семи пронумерованных номеров и заявкой на бронирование.
- `css/site.css` — стили, адаптивная сетка и анимации.
- `js/app.js` — интерактив: календарь, слайдеры, модалки, админ-панель и отправка заявки в Google Таблицу (с резервной схемой через Telegram-бота).
- `js/rooms.js` — данные семи номеров и фотографии.
- `data/site.json` — общие статусы номеров и настройки контактов (включая адрес таблицы броней `cfg.bookingApi`).
- `google-sheets/Code.gs` — скрипт для Google Таблицы: принимает заявки с сайта, пишет строку в таблицу и присылает сообщение модератору в Telegram.
- `docs/booking-google-sheets.md` — пошаговая инструкция по подключению таблицы и Telegram (10 минут).
- `demo/serve.js` — демо-стенд: сайт + настоящий `Code.gs` на мок-таблице вместо Google.
- `google-sheets/tests/backend.test.js` — автопроверка логики броней без Google-аккаунта.
- `img/*.webp` — оптимизированные фотографии; исходные JPG оставлены как fallback.
- `img/sunflower.webp` — оптимизированное реалистичное изображение круглого подсолнуха; `img/sunflower.png` — исходник с прозрачным фоном; `img/favicon.png` — компактная версия для favicon.

Проект не требует сборщика и готов к размещению на GitHub Pages или любом обычном static hosting. Важно запускать его через HTTP, потому что JavaScript использует ES-модули.

## Локальный запуск

```bash
python3 -m http.server 4173
```

После запуска откройте <http://localhost:4173>. Демо-стенд с работающим приёмом броней
запускается тем же портом через `node demo/serve.js`.

## Брони: Google Таблица + Telegram

Гость нажимает «Забронировать», заполняет форму (имя, телефон, даты, гости, номер, комментарий) —
заявка уходит в **Google Таблицу** (`google-sheets/Code.gs`, бесплатный Apps Script внутри таблицы),
а модератору в **Telegram** приходит сообщение с кнопками «✅ Подтвердить» / «❌ Отклонить».
Статус в таблице меняется по кнопке, а сайт подсвечивает занятые номера по подтверждённым броням.

Подключение — 10 минут, инструкция: **[docs/booking-google-sheets.md](docs/booking-google-sheets.md)**.
Адрес веб-приложения указывается в админ-панели (поле «📊 Google-таблица броней») и хранится
в `data/site.json` → `cfg.bookingApi`, чтобы его видели все посетители.

> ⚠️ Токен бота, лежащий сейчас в `data/site.json` (`cfg.botToken`), был доступен всем посетителям сайта —
> его нужно отозвать у @BotFather и вставлять новый только в Apps Script. После подключения таблицы
> поля `botToken`/`chatId` в `data/site.json` не нужны.

Проверка без Google-аккаунта:

```bash
node google-sheets/tests/backend.test.js   # 39 проверок логики (мок таблицы и Telegram)
node demo/serve.js                         # демо-стенд на http://localhost:4173, «таблица» — /demo/sheet
```

Пока `cfg.bookingApi` не заполнен, работает резервная схема: заявка отправляется напрямую в Telegram-бота
(как раньше). Если не настроено ни то, ни другое, форма предложит позвонить по телефону.

## Что оптимизировано

- CSS и JavaScript вынесены из `index.html` и могут кэшироваться браузером отдельно.
- Каталог номеров отделён от логики приложения.
- Фотографии отдаются через `<picture>` в WebP с JPG-fallback, а изображения карточек загружаются лениво.
- Для hero добавлен preload, а для изображений заданы размеры — меньше layout shift.
- Добавлены корректные Open Graph/Schema.org метаданные, noscript-подсказка и улучшена доступность модальных окон.
