# podsolnuh.io

Сайт гостиницы «Подсолнух» в Краснодаре со страницей онлайн-заявки на бронь.
Проект не требует сборщика и готов к размещению на GitHub Pages или обычном static hosting.
Запускайте через HTTP: JavaScript использует ES-модули.

## Структура

- `index.html` — главная страница и SEO-метаданные.
- `rooms.html` — страница заявки на бронь (только имя и номер телефона).
- `css/site.css` — стили, адаптивная сетка и анимации.
- `js/app.js` — валидация формы, модалки, админ-панель и отправка заявки в Google Таблицу.
- `data/site.json` — общие контакты и URL Apps Script в `cfg.bookingApi`.
- `google-sheets/Code.gs` — приём заявки, запись в таблицу, уведомление модератору и кнопки Telegram.
- `docs/booking-google-sheets.md` — подключение и обновление действующей таблицы / Apps Script.
- `demo/serve.js` — локальное демо с настоящим `Code.gs` на мок-таблице и мок Telegram.
- `google-sheets/tests/backend.test.js` — автопроверки формы данных, миграции, дублей и Telegram без аккаунта Google.
- `img/*.webp` — оптимизированные фотографии; JPG оставлены как fallback.

## Локальный запуск

Только статический сайт:

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

Демо с работающим локальным приёмом заявок:

```bash
node demo/serve.js
```

Откройте <http://localhost:4173/rooms.html>. На `/demo/sheet` видны записанные данные и
предпросмотр сообщения Telegram. Демо **не отправляет** данные в настоящий Google или Telegram.

## Бронирование: только имя и номер телефона

При оформлении заявки выбор номера убран — гость заполняет только два поля:

1. **Имя**
2. **Номер телефона**

Оба поля сохраняются в **Google Таблицу**, затем модератору приходит сообщение
**«🌻 Новая заявка №…»** через **Telegram-бота** с кнопками «✅ Подтвердить» / «❌ Отклонить».

В рабочей таблице видны только:

```text
Имя | Телефон
```

Четыре технические колонки (`№заявки`, `Дата заявки`, `Статус`, `Ref`) скрыты.
При обновлении прежнего формата `setup()` сначала создаёт **резервную копию всего прежнего листа**
(`Брони — архив …`), а затем переносит заявки в новый двухколоночный вид.

### Применение к действующей таблице

**Обновление файлов сайта не обновляет развёрнутый Apps Script автоматически.**
Владелец таблицы должен:

1. Заменить код в Google Apps Script файлом `google-sheets/Code.gs` и сохранить.
2. Развернуть **новую версию** существующего веб-приложения.
3. Выполнить `setup()` для переноса данных с сохранением архива старого листа.
4. Проверить тестовую заявку: запись в таблице **и** сообщение в Telegram.

Подробные шаги: **[docs/booking-google-sheets.md](docs/booking-google-sheets.md)**.
URL `/exec` уже записан в `data/site.json` → `cfg.bookingApi`; при обновлении того же развёртывания
его не нужно менять.

